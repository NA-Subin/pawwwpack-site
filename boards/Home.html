มือถือ · หน้าหลัก
ลดการเลื่อน: ปุ่มลัด 2 ปุ่ม → นับถอยหลังทริปถัดไป → ปฏิทินรวมทุกอย่าง → การ์ดเกมธีม / เทศกาล / ภารกิจ (พับได้)
1 หน้าแรกที่เห็น ปรับปรุง
  • ปุ่มลัดเหลือ 2 ปุ่ม: สร้างทริป · วางแผน
  • หารบิล / สุ่มคน ย้ายไปอยู่หน้าเครื่องมือที่เดียว
  • นับถอยหลังทริปที่ใกล้ที่สุด แตะเพื่อเปิดทริป
2 ทั้งหน้า (เลื่อนลงสุด) ปรับปรุง
  • สูง 1,497–1,524px (เดิม 2,631px)
  • เอาทริปล่าสุด / สถิติ / การ์ดซ้ำออก
  • การ์ดเทศกาล + ภารกิจวันนี้ พับเหลือแถวเดียว จำสถานะไว้ในเครื่อง
3 ปฏิทิน + อากาศวันเที่ยว ใหม่
  • ช่องสี: ทริป (ส้มอ่อน) · แผน (เหลือง) · จุด = กิจกรรม · 🎂 วันเกิดเพื่อน
  • เทศกาลอยู่แถบบนที่เดียว ไม่ซ้ำในรายการวัน
  • ไอคอนอากาศในช่องวันเที่ยว (ล่วงหน้า 16 วัน)
  • แตะวัน → รายการของวัน + คำเตือนฝน/พายุสีแดง
