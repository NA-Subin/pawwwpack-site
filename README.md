### 🎉 เกมวงเหล้า — 6 เกม ([เปิดเล่น](https://na-subin.github.io/pawwwpack-site/tools/#party))

|---|---|---|---|
| 💣 เลขระเบิด | [#party-bomb](https://na-subin.github.io/pawwwpack-site/tools/#party-bomb) | ผลัดกันทายเลข ใครโดนเลขลับแพ้ | ลุ้นก่อนเฉลย · 😱 เกือบโดน! · 🔥 โซนอันตราย 10 เลขสุดท้าย |
| 🎡 วงล้อปาร์ตี้ | [#party-wheel](https://na-subin.github.io/pawwwpack-site/tools/#party-wheel) | หมุนแล้วทำตามช่อง (แก้ช่องเองได้) | หมุน 5–10 วิ สุ่ม 6 ท่า: เกือบหยุดแล้วหมุนต่อ · หลอก 2 ครั้ง · เลยแล้วถอยกลับ · ลังเล · หมุนกลับทิศ |
| 🎲 ลูกเต๋า | [#party-dice](https://na-subin.github.io/pawwwpack-site/tools/#party-dice) | ทอยตามกติกา หรือทอยแข่งหาคนแพ้ (1–3 ลูก) | ลงทีละลูก · บางทีเกือบล้มแล้วพลิก 🤏 |
| 🃏 สุ่มการ์ด | [#party-cards](https://na-subin.github.io/pawwwpack-site/tools/#party-cards) | จั่วการ์ดคำสั่ง/คำถาม 12 สำรับ + การ์ดของแก๊ง | การ์ดพิเศษ ~1 ใน 7: 🔥 สองเท่า · 🔄 โยนต่อ · 👥 ทั้งวง · 🛡️ บัตรรอด |
| 🎯 หมุนลูกศร | [#party-arrow](https://na-subin.github.io/pawwwpack-site/tools/#party-arrow) | วางมือถือกลางวง ลูกศรชี้ใคร → ตอบคำถามคนที่หมุน หรือดื่ม แล้วคนนั้นหมุนต่อ | ท่าหมุน 6 แบบเดียวกับวงล้อ · เลือกหมวดคำถามได้ |
| 💥 ระเบิดส่งต่อ | [#party-hot](https://na-subin.github.io/pawwwpack-site/tools/#party-hot) | ตอบ 1 คำตามหมวดแล้วรีบส่งมือถือ ระเบิดตูมในมือใครคนนั้นแพ้ | เวลาลับ 15–45 วิ · ติ๊กเร็วขึ้นเรื่อยๆ · เหตุการณ์สุ่ม (กลับทิศ เปลี่ยนหมวด กระซิบ ข้ามคน) |

## อย่าแก้ไฟล์ในนี้โดยตรง

ต้นฉบับอยู่ใน repo หลักของระบบ (private) แล้วคัดลอกมาที่นี่ด้วยสคริปต์:

```bash
# ใน repo หลัก
bun scripts/sync-site.mjs        # คัดลอกไปที่ ../pawwwpack-site
cd ../pawwwpack-site
git add -A && git commit -m "Sync pages" && git push
```

push เข้า `main` แล้ว GitHub Actions จะอัปเดตเว็บให้ภายใน 1–2 นาที
